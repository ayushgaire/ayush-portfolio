==============================================
  Project & client images
==============================================

All project/client cards use real, optimized screenshots
(~1280px, <300KB each for fast loading):

  - farmfix.jpg       (live screenshot of farmfix-memory-zeta.vercel.app)
  - codyza.jpg        (live screenshot of codyza.com)
  - nepalbuddy.jpg    (live screenshot of nepalbuddy.com)

    raman-project.jpg, gedion-project.jpg

To refresh any screenshot later, capture the homepage and
compress it (macOS):

  sips -Z 1280 -s format jpeg -s formatOptions 82 in.png --out name.jpg

Filenames must match the `image` paths in src/data/content.js.
No code changes are needed if you keep the same filename.
